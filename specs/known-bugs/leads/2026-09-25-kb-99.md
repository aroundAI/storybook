# Leads from KB-99 / KB-100 (2026-09-25)

Seen while re-measuring KB-48's leads and making local runs match production.
None of these is reproduced unless it says so. The rules for working one are
in `../README.md`.

- **KB-48's two leads are resolved as "by design".** Personal owners can't
  reach the studio, and 30 policies on 8 tables refuse them. That's correct:
  the product is team accounts only (KB-99). Its "57 policies on 25 tables"
  also counted 16 policies that already had an `account_id = auth.uid()`
  branch.
- **Publishing configs accept another tenant's connection (low, reproduced in
  a rolled-back transaction, not filed).** `episode_publishing_configs`,
  `project_publishing_configs` and `short_publications` check the episode's or
  project's account, never the `platform_connection_id`'s. A team owner
  inserted a config naming another account's connection, which they cannot
  `select`: **ok, 1 row**. No consumer publishes from these configs (grepped),
  and `getProjectPublishingConfigs` inner-joins the row away. The pattern that
  closes it already exists: `channel_analytics_settings` and
  `analytics_experiments` use a composite FK `(connection_id, account_id)`.
- **Any team owner can edit the global external-sources registry (medium?,
  read only).** `packages/features/episodes/src/server/external-context-actions.ts:238-247`
  requires an `owner` membership on *any* account, then writes the global
  registry through the admin client. Anyone can create a team, so anyone can
  become an owner.
- **Other flags differ between `.env` and the deploy (read only).**
  `NEXT_PUBLIC_ENABLE_PERSONAL_ACCOUNT_DELETION`,
  `NEXT_PUBLIC_ENABLE_TEAM_ACCOUNTS_DELETION` and
  `NEXT_PUBLIC_ENABLE_TEAM_ACCOUNTS_BILLING` are `true` in `apps/web/.env` and
  unset in `sst.config.ts`, so deploys get the code default, `false`. So
  account deletion, which KB-1's specs exercise, is enabled locally and
  **disabled in every deploy**. Whether that is intended is an owner question.
  KB-99 bound only the two flags it was approved for.
