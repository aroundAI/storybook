## KB-158 — The Language Comparison tooltip shows a language's views as dollars

> **Fixed (2026-10-01), #520.** The tooltip's formatter is now
> `formatLanguageComparisonTooltip`
> (`packages/features/content-analytics/src/lib/language-comparison-tooltip.ts`).
> It picks the format by the item's `dataKey` from one series record, and the
> `<Bar>` takes its name from the same record. A series it does not know reads
> as a plain number, because nothing on this chart is money. The unused
> `engagement` and `revenue` fields are gone from the chart data. Hovering
> English now reads `Views : 1.1K`, as the axis does (`.local-ci/evidence/kb-158/after/`;
> before, `Views : $1080.00`, in `before/`).
> `chart-tooltip-evidence.spec.ts` reads the hovered tooltip's text and fails
> on `$`. On the old formatter it failed in both themes with
> `Views : $1080.00`. `language-comparison-tooltip.test.ts` failed 3 of 3 on
> the old formatter. Fixing the class: no other chart tooltip in the repo
> formats a non-money value as currency. The trend, comparison, performance
> and subscriber tooltips format counts, and the revenue chart formats money
> through `formatCurrencyAmount`.

**Severity:** Low. Hovering a bar on the Language tab's Language Comparison
chart shows the language's view count formatted as money: 1,080 views reads
"Views : $1080.00". The bar's length is right; only the tooltip's figure is
mislabelled, but it states a revenue that does not exist. **Found:**
2026-10-01, in the screenshots taken for KB-146.

The tooltip's formatter picks a format by series name
(`packages/features/content-analytics/src/components/analytics-enhancement-cards.tsx:118-125`):
`'views'` gets a count, `'engagement'` a percentage, anything else dollars.
Recharts passes the series' display name, and the one `<Bar>` is named
`"Views"` (`:136`), so the comparison `name === 'views'` never holds and every
value falls through to `$${value.toFixed(2)}`.

### Reproduced (2026-10-01)

`apps/e2e/tests/analytics/chart-tooltip-evidence.spec.ts` seeds three English
videos with 120 views a day for three days (1,080 views). Hovering the
English bar, in a production build reading a local ClickHouse, the tooltip
reads `Views : $1080.00` in both themes
(`.local-ci/evidence/kb-146/comparison-light.png`, `comparison-dark.png`).

### Proposed fix

Key the format on the `dataKey` Recharts also passes (the formatter's third
argument's `dataKey`), not on the display name, or give the `<Bar>` the
lowercase name the formatter expects and label it separately. Then assert the
tooltip's text in the KB-146 spec, which already hovers this bar.

### Acceptance criteria

- [x] Hovering a bar shows its views as a count, formatted as the axis is, with no currency
- [x] A browser test reads the tooltip's text and fails on `$`
