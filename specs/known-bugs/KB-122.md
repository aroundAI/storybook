**Severity:** Low — no user sees it; it misled whoever read the docs to change

### What the docs said

The root `CLAUDE.md` ("Scene-by-Scene Shot Generation", copied into
`AGENTS.md` and `GEMINI.md`), `docs/ARCHITECTURE.md` and the episodes README
described shot lists as built by `buildGlobalShotContext()` →
`filterContextForScene()` per scene → `executeLLM('scene-shot-generation')`
→ `aggregateSceneResults()` → `batchCreateShotsAction()`, claiming "50-80%
token savings per scene". They cited `packages/features/episodes/src/server/context-builder.ts`,
and FILM-209's `replacement` pointed at `buildGlobalShotContext`.

### What the code does

**Scene-by-scene, parallel shot generation is live**, in a different place:
Visual Studio / screenplay screen / bulk generate → `generateShotListAction`
(`packages/features/episodes/src/lib/server/mutations/shot-list-actions.ts`,
queues `jobType: 'shot-generation'`) → LLM worker `index.ts` →
`processShotGeneration` (`apps/web/lambda/llm-worker/handlers/shot-generation.ts`:
`buildEpisodeContext`, `formatCharactersForVeoPrompt` / `formatLocationsForVeoPrompt`)
→ `runShotOrchestrator` (Reel Scout → Shot Director → Shot Quality). The
Shot Director (`packages/features/episodes/src/agent/skills/shot-director-skill.ts`)
calls `scene-shot-generation` once per scene, in parallel batches of 5 (3
when an episode has more than 15 scenes), with `Promise.allSettled` per
batch, and numbers the shots in order. Owner-confirmed flow: Ideation →
Story → Screenplay → scenes → shots per scene in parallel.

**What was dead** was the older in-process pipeline's copy. In `e2d42522`
(2026-01-18), `packages/features/episodes/src/server/context-builder.ts`
moved into the worker and `shot-list-actions.ts` stopped calling it (it had
called `buildGlobalShotContext` and `filterContextForScene` in process, at
`:504` and `:100` of `e2d42522^`), becoming the job above. From then on
`buildGlobalShotContext`, `filterContextForScene`, `formatSceneForPrompt`,
`formatFilteredCharactersForPrompt`, `formatCharactersMinimal`,
`formatLocationsMinimal`, `formatFilteredLocationsForPrompt`,
`extractSceneCharacters`, `extractSceneLocation`, `extractReferenceImages`
and `buildVeoNegativePrompt` had no caller. `git grep` found each only at
its definition, and `git log -G` found no handler that ever called them.
`packages/features/episodes/package.json` still exported
`./server/context-builder`, which pointed at nothing.

**One difference from the docs:** the live Shot Director gives every scene
the episode's full character and location context. The per-scene context
filtering, where the documented saving came from, existed only in the dead
copy, and the 50–80% figure was never measured. If token cost per scene
matters, filtering can be added to the Shot Director. Start from a
measurement on a seeded episode.
