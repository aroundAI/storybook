## KB-126 — The season outliner sends characters, locations and recurring elements under names its prompt does not read

**Severity:** Medium — every season outline is written without the project's
characters, locations or recurring elements, and the model is sent the
literal placeholder text. **Found:** worker-authz, fixing KB-121 (#405).

`generateSeasonOutline` (`packages/features/episodes/src/agent/skills/season-outliner-skill.ts`)
calls the `season-outline` prompt with `existing_characters`,
`existing_locations` and `recurring_element`. The template's variables are
`characters`, `locations` and `verified_facts`; it has no recurring-element
variable at all. Unknown variables are ignored and the template's own
placeholders are left as they are.

**Reproduced** by rendering the template with the skill's keys
(`loadAndRenderPrompt('season-outline', …)`, canary values in each): none of
the three canaries is in the prompt, and it reads
`**Characters**:\n{{characters}}\n\n**Locations**:\n{{locations}}` verbatim.

Verified facts reach the orchestrator's prompt (KB-71) but not the outliner's
template either: the skill has no facts parameter.

### Proposed fix

Send the template's names (`characters`, `locations`), add a
`recurring_elements` variable, and pass the facts through, as KB-121 did for
the neighbouring outlines. Add a check that every variable a skill sends is
one its template declares. Coordinate with #378 and #382, which edit the same
skill and the season prompts.
