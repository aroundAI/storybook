## KB-168 — Likes, comments, shares and engagement read 0 where nothing was measured

> **Fixed (2026-10-05), #642 and #648, as two later entries.** The
> counts were fixed as KB-192 (#642): `queryTotalsSingle` and
> `NO_ROWS_TOTALS` return null likes, comments and shares over no rows,
> and so does `getEmptyDashboardData`. The rate was fixed as KB-194
> (#648): `displayedEngagementRatePercent` is null over zero or null
> views, the company dashboard's Avg Engagement and each top-content line
> say not measured, and a season's or project's average is null when no
> episode's rate was measured. Neither entry named this one when it was
> filed.

**Severity:** Low. A team whose publishes have no rows yet, or whose server
reads no ClickHouse, sees Likes 0, Comments 0 and Shares 0 on its home
dashboard beside Views "Not measured". A team whose rows counted 0 views
sees Avg Engagement "0%" and "0.0% engagement" on its top content, an
engagement rate with nothing to divide by. **Found:** 2026-10-02, while
fixing KB-167, which made views over nothing measured null and left these.

### What happens

- `queryTotalsSingle` sums likes, comments and shares with `sum(…)`, which
  is 0 over no rows, and `NO_ROWS_TOTALS` (ClickHouse off) carries 0 for
  them (`packages/clickhouse/src/queries.ts:327`). `ScopeTotals` types
  them as `number`, so a null cannot reach the cards, which also read
  `data?.likes || 0` (`metric-cards.tsx`).
- `getEmptyDashboardData` gives 0 likes, comments and shares
  (`account-dashboard-actions.ts:258`).
- The company dashboard's Avg Engagement reads "0%" when views are a
  measured 0 (`company-dashboard.tsx`), and `buildTopContent` passes 0
  views to `displayedEngagementRatePercent`, which gives 0, not null
  (KB-153's rule: no views, nothing to divide by).
- A season's and project's `avgEngagementRate` are 0 when no episode's
  engagement was measured (`aggregation-queries.ts`), typed `number`.

Reproduced on lane B (ClickHouse 24.8) with this branch's dev server:
`kb167-1-youtube-team-no-rows.png` shows Likes, Comments and Shares 0 for
a YouTube team with no rows; `kb167-2-youtube-team-measured-zero.png`
shows Avg Engagement "0%" and "0 views • 0.0% engagement" for a team whose
one row counted 0 views.

### Proposed fix

As KB-167 did for views: null over no rows and in the empty factories,
with `ScopeTotals` and `AnalyticsTotals` typing the counts `number | null`
so no reader can turn the null back into 0; the cards then say "Not
measured". An engagement rate over 0 views is null. A row that counted 0
likes still reads 0.

### Acceptance criteria

- [ ] The company dashboard's Likes, Comments and Shares cards read "Not
  measured", not 0, for a team whose publishes have no rows in the window,
  with ClickHouse off, and with no publishes.
- [ ] Avg Engagement and a top-content engagement rate read "Not measured"
  when views are 0, not "0%".
- [ ] A measured 0 (rows with 0 likes) still reads 0.
