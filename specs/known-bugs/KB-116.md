## KB-116 — The season-arc evaluator and the translation verifier call story-quality without its required variables

> **Fixed (2026-09-25), #PRNUM.** Each tool now calls a prompt that asks for
> what it reads: `quality-evaluation/season-arc` (arc progression, conflict
> diversity, character arc coherence, weak episodes, verdict) and
> `quality-evaluation/translation-quality` (score, divergent lines, cultural
> issues, timing violations, verdict). Both are Zod-validated and registered.
> Against the AI sandbox, both orchestrators run with no tool failure, and the
> season's arc score and translation's verification score come from the
> evaluations. The entries leave `KNOWN_TOOL_FAILURES` and `KNOWN_WRONG_READS`,
> which went red, as designed, the moment the fix landed.

**Severity:** Low. Both are quality checks, and each orchestrator carries on
without them. The season's arc score and the translation's verification
score and verdict never come from an evaluation; they are whatever the
director model writes in its final answer. **Found:** FILM-1803, driving the
orchestrators against the AI sandbox, 2026-09-25.

Both tools call the `quality-evaluation/story-quality` prompt, which requires
`title` and `story_text`, and pass neither:

| Tool | Skill | Passes |
|---|---|---|
| `evaluateSeasonArc` | `packages/features/episodes/src/agent/skills/season-arc-evaluator-skill.ts` | `content`, `genre`, `season_premise` |
| `verifyTranslation` | `packages/features/episodes/src/agent/skills/translation-verifier-skill.ts` | `story_content`, `context_hint` |

So `loadAndRenderPrompt` throws
`Missing required variables for prompt quality-evaluation/story-quality: title, story_text`
on every call. Behind that, the arc evaluator also reads fields
(`overallArcScore`, `arcProgression`, `weakEpisodes`, …) that
`story-quality`'s schema does not produce, so fixing the variables alone
would return `undefined`s: these tools need a prompt that evaluates a season
arc and a translation, not a story.

`prompt-format.test.ts`'s caller-shape guard (KB-115) records the arc
evaluator's reads in `KNOWN_WRONG_READS` until this is fixed.

**Reproduced** by running `runSeasonOrchestrator` and
`runTranslationOrchestrator` against the AI sandbox
(`apps/vendor-sandbox/__tests__/orchestrators.test.ts`, `KNOWN_TOOL_FAILURES`).
