## KB-162 — The company dashboard shows an unmeasured watch time and follower gain as 0m and 0

> **Fixed (2026-10-02), #TBD.** `queryTotals` sums the three columns a
> platform may not report — saves, watch time, follower gain — with
> `sumIf(col, col IS NOT NULL)` beside KB-114's `count(col) > 0` flag, and
> returns null where no row measured one (`ScopeTotals`, a type of its
> own, so a caller cannot take the null for a number). Over no rows at all,
> and with ClickHouse off, they are null too: nothing measured them. The
> account dashboard passes null to the cards and leaves saves out, and the
> cards render null as "Not measured" (`data-test="metric-not-measured"`),
> the card state KB-149 added — the `metric-cards.tsx`, `types.ts` and
> insights-schema changes here are KB-149's, line for line, so the two
> branches merge cleanly.

> time) and `queryPlatformBreakdown` (saves) read the same NULL sums as 0;

**Severity:** Low — every team whose published videos are all on TikTok
reads "Watch Time 0m" and "Subscribers 0" on its home dashboard, where
TikTok reported nothing. A 0 reads as "nobody watched", a measurement the
data does not support. **Found:** 2026-10-01, by the KB-149 fix, which
fixed the episode page and left the company dashboard: it reads
`queryTotals`, which has no `measured` flag.

### What happens

TikTok's sync writes NULL for watch time, follower gain and saves (KB-114),
and ClickHouse sums a column of only NULLs to NULL. `queryTotalsSingle` read
each sum with `Number()`, and `Number(null)` is 0. The account dashboard
(`getAccountDashboardData`) passed that 0 to `MetricCards`, which drew it.

Reproduced against lane B's ClickHouse 24.8: two TikTok rows with 100 views
each and NULL for the three columns read back from `queryTotals` as

```json
{"views":200,"likes":20,"comments":2,"shares":2,"saves":0,
 "watch_time_seconds":0,"revenue_cents":0,"subscribers_gained":0}
```

while the server's own answer for the sum is `null`
(`SELECT sum(watch_time_seconds)` over the same rows, type
`Nullable(UInt64)`).

### Acceptance criteria

- [x] `queryTotals` returns null for a column no row in the scope measured,
  and the sum of the measured rows otherwise (a measured 0 stays 0).
- [x] The company dashboard's Watch Time and Subscribers cards read "Not
  measured" for an all-TikTok team, and a figure once a platform measured
  it.
- [x] The daily series and platform split do not turn the same NULL into 0.
- [x] The Views card reads "Not measured" for a Facebook-only team.
- [x] A season's, project's and content list's saves, an experiment
  snapshot's watch time and a format family's follower gain add only
  measured figures, and are null when none was measured.
