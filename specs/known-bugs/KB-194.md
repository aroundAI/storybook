## KB-194 — The engagement rate reads 0% where nothing was measured

> **Fixed (2026-10-05), #648.** `displayedEngagementRatePercent`
> (`@kit/clickhouse`, `measures.ts`) returns null when the views are null
> or zero, or when a likes, comments or shares count is null.
> `recordedEngagementRatePercent` and `recordedLikesAndCommentsPercent`
> return `RecordedRate | null` through it, and every caller passes the
> counts as read: the per-site `views === null ? null : …` guards and
> `?? 0` fills are gone (`engagementCounts` in `aggregation-queries.ts`
> too). A season's or project's average is `meanRate`, over the rates that
> were measured, null when none was. The project overview, the Overview and
> season/project cards, the language, platform-by-language and format
> cards, and the shorts-versus-long-form difference say "Not measured". The
> AI-insights input's `avgEngagementRate` is nullable. A measured 0%
> (counts of 0 over views) is still 0%. Nothing else about the rate
> changes, and it is not switched to engaged views.
>
> **Owner's decision, 2026-10-05:** the FILM-1722 §12 hold on that 0
> (2026-09-22) is lifted for this unmeasured case only; recorded in FILM-1722
> §12.

**Severity:** Low — a project before its first sync, a language with no
views in the window, a platform that reports no shares. It reads as
"viewers did not engage" where nothing was measured. **Found:** KB-192
(#642) fixed the like, comment and share totals and left the rate, which
the project overview still drew as `0%` (FILM-1722 §12 held the 0).

### What happened

Reproduced on lane B: a team with one published YouTube video and no
metric rows, at `/home/<team>/studio/<project>`. The Avg. Engagement card
read **0%** with an empty bar, beside Total Views, which said Not measured.
The same 0 came out of `displayedEngagementRatePercent` (zero views), of
`emptyEngagementRate` (a scope with no publishes), of a season or project
average over no rate (`engagedEpisodes > 0 ? … : 0`), and of every site
that filled an unmeasured count with `?? 0`.

### Fix

One function (`displayedEngagementRatePercent`) holds the rule; the second
numerator the project overview uses (likes and comments, KB-171) shares it.
`engagement-rate-one-definition.test.ts` still fails any inline division.
The experiment snapshot format is unchanged.

**Acceptance criteria.**
- [x] The rate is null over zero or null views, or an unmeasured count;
  a measured 0 stays 0. `measures.test.ts` and
  `rate-denominator-records.test.ts`, red on main.
- [x] The project overview says Not measured: unit
  (`performance-insights-section.test.tsx`) and Playwright
  (`overview-trend.spec.ts`, red on main: `0%`).
- [x] Season, project, language, matrix and format reads return null where
  nothing was measured (`rate-denominator-aggregation-reads.test.ts`,
  `rate-denominator-language-reads.test.ts`).
