## KB-179 — Turbopack dev shows a Build Error overlay on any page that reaches an analytics action module

> **Fixed (2026-10-03), #575.** The eight `*-actions.ts` files under
> `packages/features/content-analytics/src/server/` no longer re-export
> types; their importers read the types from the matching `*-service.ts`.
> `use-server-exports.test.ts` now fails on `export type { X } from` in any
> `'use server'` module.

**Severity:** Medium. Developer-facing only: `next dev --turbo` renders a
Build Error overlay instead of the page, and the page returns 500. Webpack
and production builds are not affected. **Found:** FILM-1908 work (t1908),
after #559 (FILM-1906 part A) moved each analytics action's types behind a
re-export.

### What happens

`publish-notes-actions.ts` is a `'use server'` module that contained

```ts
export type { PublishNoteSaveResult } from './publish-notes-service';
```

Turbopack treats a `'use server'` module's exports as actions and refuses
anything that is not an async function, including a type re-export:

```
Only async functions are allowed to be exported in a "use server" file.
Import trace:
  Server Component:
    ./packages/features/content-analytics/src/server/publish-notes-actions.ts
```

### How it was reproduced

`main` @1b1882ad0, `next dev --turbo -p 3218`, a throwaway page importing
one module. An inline `export type X = …` compiles; the re-export form does
not:

```
publish-notes-actions   500  "Only async functions are allowed…"
video-log-actions       500  (same message)
genome-actions          500  (same message)
thumbnail-actions       200  (inline export type, episodes)
```

Seven more modules had the same line (channel-experiment, experiment,
segment, settings, signal-surface, and the three above): eight in all.

### Fix

Delete the eight re-exports, import each type from its service module
(`@kit/content-analytics/server/<name>-service`), and keep `server/index.ts`
re-exporting the types from the services. After the fix the same probe
returns 200 for all eight modules.

### Acceptance criteria

- [x] No `'use server'` module contains `export type { … } from`
      (`packages/next/__tests__/use-server-exports.test.ts`, red on `main`
      with the eight files named, green after).
- [x] `next dev --turbo` serves a page that imports each of the eight
      modules with no build error.
