## KB-147 — The scan-scope guard cannot fail on a persistent ClickHouse

> **Fixed (2026-10-01), #TBD.** `scanScopeSteps` now clears the noise
> project before it reads the baseline, not only before it inserts. With
> the fix, the same mutation that passed against leftover noise goes red.

**Severity:** Medium — no read is known to be unscoped today, but the one
guard that would say so was silent everywhere except a fresh CI container,
and local CI's lane A, which merges while GitHub Actions minutes are out,
is not fresh. **Found:** FILM-1704, adding `queryObservedCoverage` to the
step's reads.

`assert: another project's rows do not enlarge these reads` in
`packages/clickhouse/scripts/verify-queries.ts` is differential: it reads
each query's `read_rows`, inserts 50,000 rows under `NOISE_PROJECT`, reads
again, and fails a read that grew. Nothing removes the noise afterwards —
`clearNoise()` ran only *between* the two reads, before the insert. So on
any ClickHouse that has run the script before, the baseline reads already
included the previous run's 50,000 rows, the insert replaced them with the
same keys, and every read's growth was about zero whatever its SQL did.

### Reproduced (2026-10-01, lane A ClickHouse 24.8, after one full run)

With `queryObservedCoverage`'s project predicate deleted (the bound the
guard exists for):

| Noise before the baseline | Result |
|---|---|
| left from the previous run (as every rerun) | **PASS** — `11 reads, worst +2382 for +50000 rows elsewhere` |
| cleared first | **FAIL** — `coverage +199998 — not bounded by project_id` |

The same holds for every read in the step: the mutation is not specific to
the new query.

### Fix

Clear the noise before the baseline. The existing clear before the insert
stays covered by it, so it was folded in rather than kept twice.

### Acceptance

- [x] With leftover noise present and the coverage read's project predicate
      deleted, the step fails (red after the fix, where it passed before).
- [x] Unmutated, the step passes on the persistent lane A ClickHouse.
