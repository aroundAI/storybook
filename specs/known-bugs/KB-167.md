## KB-167 — The company dashboard shows 0 views when nothing has been measured (no rows yet, or ClickHouse off)

**Severity:** Low. A team whose publishes have no rows yet in the window,
or whose server reads no ClickHouse (production's state today), reads
"Views 0" on its home dashboard. A 0 says "nobody watched", but nothing was
measured. The episode page shows "Not measured" for the same state, so the
two pages disagree. **Found:** 2026-10-02, while fixing KB-166, which
expected a null there and found 0.

### What happens

- `queryTotalsSingle` returns `views: Number(row.row_count) === 0 ? 0 :
  nullableNumber(row.views)` (`packages/clickhouse/src/queries.ts:479`).
  No rows in the window gives 0 views. With ClickHouse off it returns
  `NO_ROWS_TOTALS` (`queries.ts:327`, `views: 0`).
- `getEmptyDashboardData` returns `views: 0` for both periods
  (`packages/features/content-analytics/src/server/account-dashboard-actions.ts:257`,
  `:269`). That covers a team with no projects or no publishes, and the
  `catch` taken when ClickHouse fails. Likes, comments and shares are 0
  there too.

Reproduced on lane B (ClickHouse 24.8) with a dev server on this branch. A
seeded team with one published YouTube video and no `video_metrics` rows
shows a Views card reading `"Views\n0\nNo previous period to compare"`
(probe screenshot `kb167-youtube-team-no-rows.png`, not committed).

### Proposed fix

Views over a scope where nothing was measured is null, in the same way
KB-162 made watch time and follower gain null: no rows, ClickHouse off,
and the empty dashboard. The card then says "Not measured" with KB-166's
reason. Changing this affects several cards and E2E expectations: Avg
Engagement, the platform split, and the KB-162 specs that read
"Views 180". The lead is scheduling it after #531 and KB-166 land.

### Acceptance criteria

- [ ] The company dashboard's Views card reads "Not measured", not 0, for
  a team whose publishes have no rows in the window.
- [ ] With ClickHouse off, or with no publishes, it does not read 0.
- [ ] A measured 0 (rows with 0 views) still reads 0.
