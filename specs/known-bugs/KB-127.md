## KB-127 — The Refresh button's action force-refreshes any connection id it is sent, another account's included, with the admin client

> **Fixed (2026-09-27), #425.** `refreshConnectionAction` now reads the
> connection through the caller's own client first; RLS
> (`has_account_access`) is the access check, as it already was for
> disconnect. A connection the caller cannot see is refused, as a value
> (KB-6), before `ensureValidToken` runs. The one caller, the Refresh button
> on Settings → Platforms, unwraps the result and shows the refusal.

**Severity:** High — any signed-in user who knows (or guesses) a connection
id could force-refresh another account's channel. `ensureValidToken` reads
and writes `platform_connections` with the admin client, so RLS never ran.
A refresh the vendor refuses deactivates the connection, and an X refresh
rotates its refresh token: the owner's channel stops publishing until they
reconnect. The attacker cannot read the token, but can knock any channel
offline. **Found:** the platform-admin audit, 2026-09-25.

### Reproduced (2026-09-27, `main` c7c92d2d)

`apps/e2e/tests/platform-connections/refresh-connection-authz.spec.ts`: Bob,
owner of one team, clicks Refresh on his own YouTube channel, and the request
is rewritten on its way out to name Alice's channel in another team. A local
stand-in for Google's token endpoint (`VENDOR_URL_GOOGLE_TOKEN`) refuses every
refresh and records what it was sent.

- With `main`'s action: the stand-in received **Alice's** refresh token
  (`alice-refresh`), on Bob's click.
- With the fix: nothing of Alice's is sent, her connection stays active, and
  Bob sees the refusal.

### The class

Every other caller of `ensureValidToken` / `getAccessToken` takes its
connection id from the database (the sync crons, the scheduled-publish and
token-refresh jobs, the reporting ingest) or already checks the connection's
account first (`publishToAll`, `retryPublish`, `publishSocialPost`: KB-109,
#384). The backfill route is behind `CRON_SECRET` and takes no connection id.
