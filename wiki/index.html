Storybook Platform Wiki

The complete guide to how Storybook turns a simple idea into a fully produced AI-generated video — from concept to shots to audio, with memory across episodes.

Imagine you want to make a cartoon show. You type in one sentence like "A 7-year-old detective solves mysteries using science." Then, the app writes the whole story for you, breaks it into scenes like a movie script, creates camera instructions for every shot, and even writes the sound effects and music. And the best part? It remembers everything from past episodes — so characters don't come back from the dead and plot lines stay consistent!

How Does It Know Your Show's "Style"?

Take "Little Detective Dante" — a science-based detective show for kids. The user never hardcodes "science detective" into the app. Instead, when they create the project, metadata is stored in the projects table:

{
  "name": "Little Detective Dante",
  "projectAestheticStyle": "3D Pixar/DreamWorks cartoon",
  "recurringElements": [
    {
      "name": "The Clue Board",
      "placement": "throughout",
      "purpose": "Dante organizes clues visually on his magnetic clue board"
    },
    {
      "name": "The Deduction Dance",
      "placement": "end",
      "purpose": "Dante does a silly celebration dance when he solves the case"
    }
  ],
  "characters": [
    { "name": "Dante", "role": "protagonist", 
      "description": "A curious 7-year-old who uses science to solve mysteries" }
  ]
}

This metadata is injected into every LLM prompt as context variables. The AI doesn't need to be told the style — it reads it from the project configuration, ensuring consistency across all episodes.

Architecture at a Glance

🌐
Next.js 15 + React 19
App Router, Server Actions

The frontend and server-side rendering layer. Uses TypeScript, Tailwind CSS 4, and Shadcn UI for a premium design system.

🗄️
Supabase PostgreSQL
Database + Auth

Relational data with Row-Level Security, connection pooling, and built-in OAuth/MFA authentication.

⚡
AWS Lambda + SQS
Background Processing

7 Lambda functions process LLM jobs, email, video rendering, and publishing via 4 SQS queues with dead-letter queues.

🧠
Canon Memory System
Continuity Engine

Token-budgeted memory context with immutable events, character states, narrative threads, and episode summaries.
