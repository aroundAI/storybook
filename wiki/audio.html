🔊 Audio Studio

TTS, music generation, voice cloning, and the audio timeline.

After creating the video shots, we need voices and music! The Audio Studio turns written dialogue into spoken words using AI voices, adds background music, and mixes in sound effects like footsteps or birds chirping.

TTS (Text-to-Speech)

Text-to-Speech is the backbone of the Audio Studio. Every line of dialogue written in the Screenplay stage gets converted into a spoken audio clip using ElevenLabs' API. The system supports per-character voice assignment and emotion control.

ElevenLabs Integration

The platform uses the ElevenLabs Multilingual v2 model for natural-sounding speech synthesis. Each API call sends a single dialogue line and receives a high-quality audio clip in return.

// TTS request structure
{
  text: string;            // The dialogue line to synthesize
  voice_id: string;        // Character's assigned ElevenLabs voice
  model_id: string;        // "eleven_multilingual_v2"
  voice_settings: {
    stability: number;     // 0.0–1.0, lower = more expressive
    similarity_boost: number; // 0.0–1.0, higher = closer to reference
    style: number;         // 0.0–1.0, emphasis on style transfer
  }
}

Emotion Tags

The Screenplay stage embeds emotion tags directly into dialogue lines. These tags modify TTS parameters at synthesis time to produce emotionally appropriate speech:

😆
[excited]
Higher pitch, faster pace

Maps to stability: 0.3, style: 0.8. Used for moments of discovery, celebration, or surprise. The voice becomes more animated and energetic.

😰
[nervous]
Slight tremor, halting delivery

Maps to stability: 0.4, style: 0.6. Used for tense moments, uncertainty, or fear. The voice wavers slightly and pacing becomes irregular.

🤫
[whisper]
Soft, breathy delivery

Maps to stability: 0.7, style: 0.3. Used for secrets, suspenseful reveals, or quiet observations. Volume is reduced and breathiness is increased.

😠
[angry]
Forceful, clipped speech

Maps to stability: 0.5, style: 0.9. Used for confrontation or frustration. The voice becomes more intense with sharper consonants.

Per-Character Voice Assignment

Each character in the project's character registry can be assigned a unique ElevenLabs voice. This mapping is stored in the character_voices table:

// character_voices table structure
{
  character_id: uuid;        // FK → project_characters.id
  voice_id: string;          // ElevenLabs voice identifier
  voice_name: string;        // Human-readable label (e.g., "Young Boy - Curious")
  is_cloned: boolean;        // true if using a custom-cloned voice
  stability: number;         // Default stability for this character
  similarity_boost: number;  // Default similarity for this character
}

When the TTS engine processes a dialogue line, it looks up the speaking character's voice settings and applies them automatically. Emotion tags then further modify these defaults.

Music Generation

Background music is generated with ElevenLabs. The system creates music tracks that match the emotional tone of each scene, with careful attention to BPM (beats per minute) and musical key.

🎵
ElevenLabs Music
AI-powered music composition

Each scene in the screenplay includes mood metadata that feeds into the music generation prompt. The system generates background tracks that match the scene's emotional arc — upbeat for chase sequences, gentle for tender moments, suspenseful for mystery reveals.

BPM & Key Matching

Music tracks are generated with specific BPM and key constraints to ensure consistency across an episode:

Scene Mood Target BPM Suggested Keys Style
Adventure / Chase 140–160 D major, E major Orchestral, energetic
Mystery / Suspense 80–100 D minor, B minor Ambient, tension-building
Emotional / Tender 60–80 C major, F major Piano-led, gentle strings
Comedy / Playful 120–140 G major, A major Bouncy, pizzicato, woodwinds
Triumph / Resolution 100–120 C major, D major Full orchestra, brass swells
💡 Key Consistency

When multiple scenes share a sequence (e.g., a chase that spans 3 scenes), the system locks the musical key across all of them to prevent jarring transitions. The BPM can vary slightly for dramatic effect, but the key stays anchored.

Sound Effects

Sound effects (SFX) are derived from the audio cues embedded in each screenplay scene. During the Screenplay stage, the AI generates structured audio cue metadata alongside dialogue:

// Audio cues from a screenplay scene
{
  audioCues: [
    { type: "ambient", description: "Busy zoo atmosphere — distant animal calls, children laughing" },
    { type: "sfx", description: "Macaw squawk — loud, close, startling", timestamp: "00:02:15" },
    { type: "sfx", description: "Footsteps on gravel — quick, running", timestamp: "00:02:18" },
    { type: "ambient", description: "Wind rustling through tropical plants" }
  ]
}
🌿
Ambient Sounds
Continuous background audio

Ambient sounds run for the duration of a scene. They set the atmosphere — a busy schoolyard, a quiet forest, rain on a window. These are placed as full-length tracks on the timeline.

💥
Point Effects (SFX)
Timestamped one-shot sounds

SFX are short, precise sounds tied to specific moments — a door slam, a gasp, a clue discovery "ding." They're placed at exact timestamps on the timeline.

SFX can be sourced from an AI generation service or from a curated library of pre-made sound effects. The system prefers AI-generated SFX for unique sounds and library clips for common ones (footsteps, doors, etc.).

Audio Timeline

The Audio Timeline is the mixing board of the Audio Studio. It positions every audio element — dialogue, music, and SFX — on a multi-track timeline synchronized to the episode's video shots.

The timeline is divided into three parallel tracks:

🗣️
Dialogue Track

Contains all TTS-generated voice clips. Each clip is positioned based on the dialogue line's sequence number in the screenplay. Gaps between clips are calculated from estimated shot durations.

🎶
Music Track

Background music runs continuously beneath dialogue. Volume is automatically ducked (reduced) when dialogue is playing and restored during non-dialogue segments.

🔉
SFX Track

Point effects and ambient sounds. Ambient clips span entire scenes. Point SFX are placed at precise timestamps derived from screenplay audio cues.

Voice Cloning

For projects requiring unique character voices that don't exist in ElevenLabs' stock library, the platform supports custom voice cloning. This creates a synthetic voice model from reference audio samples.

🎤
Custom Voice Profiles
Per-character cloned voices

Users upload 1–5 minutes of reference audio for a character. ElevenLabs' Instant Voice Cloning API creates a custom voice model that captures the speaker's unique timbre, cadence, and accent. This cloned voice is then assigned to the character and used for all their dialogue.

⛔ Voice Cloning Safeguards
  • Consent verification required. Users must confirm they have legal rights to clone the voice before the API call is made.
  • Project-scoped only. Cloned voices are isolated to the project that created them. They cannot be shared across projects or accounts.
  • Rate-limited. Each project is limited to 10 cloned voices to prevent API abuse.

Data Flow: dialogue_lines → TTS

The dialogue_lines table is the bridge between the Screenplay stage and Audio generation. Every line of character dialogue is stored here with rich metadata that feeds directly into the TTS engine:

// dialogue_lines table
{
  id: uuid;
  episode_id: uuid;          // FK → episodes.id
  scene_number: number;      // Which scene this line belongs to
  sequence_order: number;    // Order within the scene
  character_id: uuid;        // FK → project_characters.id
  character_name: string;    // Denormalized for display
  dialogue_text: string;     // The actual spoken text
  emotion: string;           // "excited" | "nervous" | "whisper" | …
  audio_url: string | null;  // S3 URL after TTS generation
  duration_ms: number | null; // Audio clip duration after synthesis
}

A single dialogue line flows through the system like this:

// 1. Screenplay outputs:
"Dante": "[excited] Look at this feather — it's from the missing macaw!"

// 2. Stored in dialogue_lines as:
{
  character_name: "Dante",
  dialogue_text: "Look at this feather — it's from the missing macaw!",
  emotion: "excited"
}

// 3. TTS engine reads this, applies Dante's voice + excited settings
// 4. Resulting audio clip uploaded to S3, URL saved back to dialogue_lines
