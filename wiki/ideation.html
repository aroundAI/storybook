💡 Ideation Stage

The first stage of the content pipeline. Transform a single-sentence premise into multiple scored story concepts — complete with viral potential analysis, thematic depth, and visual hooks.

You give the app one sentence — like "Dante solves a mystery at the zoo." The app then comes up with 3 different story ideas based on that sentence, each with a catchy title, a summary, and a score for how likely it is to go viral!

What Goes In

The ideation stage accepts a minimal explicit input from the user, but enriches it heavily with project context behind the scenes.

Explicit User Input

The user provides three fields via the Ideation form:

// IdeationInput schema
{
  episodeId: string;        // Links to the episode being created
  premise: string;          // 10–500 characters — the seed idea
  numberOfIdeas: number;    // 1–5, defaults to 3
}

Implicit Context Injection

Before the LLM call fires, the system loads rich context from the project's metadata tables. This is what makes the AI "know" your show:

👥
Characters
From project_characters table

Full character registry — names, roles, physical descriptions, personality traits, relationships. The AI can only use characters that exist here.

📍
Locations
From project_locations table

All available settings — Dante's Treehouse Lab, the School hallway, the Park. The AI must ground stories in these locations.

📺
Previous Episodes
From episodes table (SCORE summaries)

Titles and summaries of past episodes, so the AI avoids repeating plot points and maintains series continuity.

🔁
Recurring Elements
From projects metadata

Signature moments with specific placement rules — "The Clue Board" (throughout), "The Deduction Dance" (end of episode).

🎭
Genre & Audience
From projects metadata

Genre (e.g., "Children's Mystery"), target audience (e.g., "Children 4–8"), and content style preferences that shape tone and complexity.

🎨
Visual Style
From projects metadata

The aesthetic style (e.g., "3D Pixar/DreamWorks cartoon") that informs visual potential descriptions in each idea.

The Ideation Prompt

The system prompt is constructed from three distinct layers, each with a specific purpose. This layered architecture makes prompts modular and testable.

Layer 1 — Role Definition

Sets the AI persona. The system prompt opens with:

"You are an expert story consultant specializing in children's content
creation. You generate creative, engaging story concepts that are
optimized for visual storytelling and audience engagement."

This framing ensures the model responds as a domain expert rather than a generic assistant. The persona primes it for creative, structured output.

Layer 2 — Viral Scoring Framework

This is the secret sauce. The prompt defines a proprietary scoring rubric that forces the model to evaluate each idea's potential to spread:

🎯
Curiosity Gap

Does the concept create a "I need to know what happens" tension? Scored 1–10.

❤️
Emotional Anchor

Is there a universal feeling — wonder, fear, joy — that anyone can connect to? Scored 1–10.

🚀
Shareability

Can the concept be described in one "you gotta see this" sentence? Scored 1–10.

Layer 3 — Output Format Constraint

The final layer instructs the model to respond in a strict JSON format. Under the hood, the platform uses generateObject() from the Vercel AI SDK, which enforces schema compliance at the API level — not just in the prompt text.

What Comes Out

The LLM responds with a structured JSON object containing the requested number of story ideas. Each idea includes metadata designed for both human review and downstream pipeline consumption:

{ "ideas": [ { "title": "The Case of the Missing Macaw", "logline": "When the zoo's star macaw vanishes on the morning of the big bird show, Dante must follow a trail of rainbow feathers — and discover the bird was trying to protect something precious.", "themes": ["friendship", "responsibility"], "hook": "The macaw left behind a trail of colored feathers, each one pointing to a different part of the zoo — but the trail doesn't lead to the exit. It leads deeper inside.", "visualPotential": "Vibrant zoo environments with tropical bird habitats, dramatic close-ups of feather clues under Dante's magnifying glass, and a heartwarming reveal scene.", "viralPotential": { "score": 8, "curiosityGap": "Why did the macaw leave clues behind — and what is it protecting?", "emotionalAnchor": "A child protecting an animal friend who can't speak for itself", "shareability": "You have to see what Dante discovers at the end of the feather trail..." } }, { "title": "The Midnight Howler", "logline": "Strange howling sounds at night are scaring visitors away from the zoo. Dante suspects it's not an animal at all...", "themes": ["courage", "empathy"], "hook": "The howling only happens when the moon is full — and it's coming from the one enclosure that's supposed to be empty.", "visualPotential": "Atmospheric nighttime zoo scenes, moonlit silhouettes, dramatic sound-tracking sequences with Dante's homemade listening device.", "viralPotential": { "score": 7, "curiosityGap": "What's making sounds in an empty enclosure?", "emotionalAnchor": "Overcoming fear to help someone who's scared and alone", "shareability": "Wait until you find out what was REALLY making those sounds..." } } ] }

The user sees these ideas as interactive cards in the Ideation UI. They pick one (or edit it), and that becomes the input to the Story Generation stage.

Critical Constraints

⛔ Hard Rules — Breaking These Fails the Pipeline
  • Characters are locked. The AI must use ONLY characters defined in the project's character registry. It cannot invent new characters during ideation.
  • Locations are locked. Stories can only take place in locations from the project's location list. No new settings.
  • No plot recycling. The AI must not repeat plot points, conflicts, or resolutions from previous episodes. SCORE summaries are injected to enforce this.
  • Recurring elements are mandatory. If "The Clue Board" is marked as placement: throughout, every idea must naturally incorporate it. If "The Deduction Dance" is placement: end, it must appear at the episode's conclusion.
💡 Why So Strict?

These constraints exist because later pipeline stages (Story → Screenplay → Visual Studio) trust the ideation output as canon. If ideation invents a character that doesn't exist in the registry, downstream shot generation will try to render them — but there's no physical description to reference. The constraint chain prevents cascading failures.

This is the lightest model used in the entire pipeline. Later stages like Screenplay and Shot Generation use more powerful models (e.g., gemini-2.5-flash) because they require precise adherence to complex formatting rules.

Deep Dive: The Viral Scoring System

The viral scoring system isn't just a gimmick — it's a structured framework for evaluating whether a story concept has the properties that make content spread on social platforms. Each dimension targets a different psychological mechanism:

🎯 Curiosity Gap (Weight: High)

Based on George Loewenstein's "information gap" theory. The best content creates a gap between what you know and what you want to know. In practice, this means the idea's hook should raise a question that feels urgent to answer.

Scoring guide:

  • 1–3: Predictable outcome ("Dante finds the missing toy") — no tension
  • 4–6: Mild surprise ("Dante finds the toy, but it's in a strange place") — some pull
  • 7–10: Irresistible mystery ("The toy was never missing — it was hiding on purpose") — compulsive engagement

❤️ Emotional Anchor (Weight: High)

Content spreads when it triggers a universal emotion — not a niche feeling, but something everyone has experienced: protecting a friend, being afraid of the dark, the joy of discovery. The emotional anchor is the "why should I care?" factor.

Scoring guide:

  • 1–3: Abstract or intellectual theme only — hard to feel
  • 4–6: Relatable but not visceral — "that's nice"
  • 7–10: Gut-level connection — makes you think of your own childhood

🚀 Shareability (Weight: Medium)

Can the concept be compressed into a single sentence that makes someone say "you HAVE to watch this"? This tests the concept's word-of-mouth potential. If it takes a paragraph to explain why it's interesting, it won't spread.

Scoring guide:

  • 1–3: Requires full context to understand appeal
  • 4–6: Can be summarized but doesn't create urgency
  • 7–10: One-sentence pitch that creates immediate "I need to see this"

📊 The Combined Score

The final viralPotential.score is a weighted composite of all three dimensions. It's not a simple average — curiosity gap and emotional anchor are weighted more heavily because they're stronger predictors of engagement than shareability alone:

// Approximate weighting (internal to the prompt)
score = (
  curiosityGap × 0.4 +
  emotionalAnchor × 0.4 +
  shareability × 0.2
) / 1.0

Ideas scoring 7+ are visually highlighted in the UI with a "🔥 High Potential" badge. Ideas below 5 get a subtle warning indicator, encouraging the user to refine the premise.
